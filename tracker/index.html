Como funciona o Score NLE

Cada grupo recebe uma pontuacao de 0 a 100 com base em quatro componentes ponderados. O sistema analisa o historico de cliques para determinar quais grupos trazem mais resultados para a campanha Nome Limpo Express.

score = (cliques_norm x 0.40) + (CTR_norm x 0.30) + (tendencia x 0.20) + (consistencia x 0.10)

Pesos dos Componentes

Cliques 40%
CTR 30%
Tend. 20%
Consist. 10%

Cliques Normalizados (40%)

Total de cliques do grupo dividido pelo maximo de cliques entre todos os grupos, multiplicado por 100. Mede o volume absoluto de engajamento.

CTR — Taxa de Cliques (30%)

Cliques dividido pelo numero de membros, multiplicado por 10.000. Normalizado em relacao ao grupo com maior CTR. Mede a eficiencia do grupo independente do tamanho.

Tendencia (20%)

Comparacao dos cliques dos ultimos 7 dias versus os 7 dias anteriores. Um grupo com tendencia de alta recebe pontuacao maior. Captura o momentum recente.

Consistencia (10%)

Baseada no desvio padrao dos cliques diarios. Quanto menor a variacao, mais consistente e confiavel o grupo. Calculada como 100 - (desvio_padrao x 20), limitada entre 0 e 100.
